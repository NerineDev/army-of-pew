# Army of Pew

**Army of Pew** is a lightweight arcade game project built around fast, satisfying runs and a deliberately focused gameplay loop.

The project explores simple controls, escalating action, meaningful moment-to-moment choices, and short sessions that are easy to pick up and play.

## Status

Early development / prototyping.

## Goals

- Fast, approachable arcade gameplay
- Short, replayable levels
- Clear progression without unnecessary complexity
- Fair monetization that does not sell gameplay power

More details will be shared as the project develops.

## Repository

This repository is the public home for Army of Pew. Development code and internal design documentation are maintained separately while the game is in active development.
